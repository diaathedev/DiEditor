# DiEditor
Lightweight CapCut-style editor 

    pip install -r requirements.txt
    python main.py

Linux extras: `sudo apt install libportaudio2 libxcb-cursor0` (and optionally `ffmpeg`).

Shortcuts: Space play/pause - S split - R razor tool - Del delete (Ripple toggle) - I/O mark in/out
Ctrl+Del delete marked range - Left/Right step frame - Ctrl+Wheel zoom timeline - Ctrl+Z/Y undo/redo
